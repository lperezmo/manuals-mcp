Add it to the Muse app

  1. Copy the link below.
  2. In the Muse app, paste the link and say you want to connect to it.
  3. Tap Connect on the card Muse shows. When it asks for a Client ID, paste this one and tap Add:
  4. Sign in with the same email you use here.
  5. Muse checks each tool before it uses it. If one seems missing later, ask it to review the Manuals tools again.

The chat on this site runs on Muse too, so you can also just ask from Home.

Add it to Claude

  1. Copy the link below.
  2. In Claude, open Settings, then Connectors, then Add custom connector.
  3. Name it Manuals, paste the link and choose Add.
  4. Choose Connect and sign in with the same email you use here.

Add it to ChatGPT

  1. Copy the link below.
  2. In ChatGPT, open Settings, then Apps, then Advanced settings, and turn on Developer mode.
  3. Choose Create, name it Manuals, paste the link and pick OAuth.
  4. Sign in with the same email you use here.
